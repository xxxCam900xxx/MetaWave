# MetaWave
MetaWave ist ein Audio-Media-Server mit Client. Der Server lädt monatlich YouTube-Playlists herunter und streamt sie endlos im Shuffle-Modus. Der Client verbindet sich sicher per Zugangscode, ermöglicht gleichzeitiges Hören, Lautstärkeanpassung, Songs überspringen, favorisieren und in die Warteschlange setzen.
